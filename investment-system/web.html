FIRST PRINCIPLE

先想清楚,赚的是什么钱?

投资 = 增长游戏
挣企业增长、GDP、货币扩张的钱
投机 = 零和博弈
挣情绪波动与非对称信息的钱,长期期望为负
投资与投机，两套玩法,两套规则,不能混用。
市场里 80% 的波动是情绪的钱——你可以赚它,但要知道自己在赚它,并用交易的规则(止损、仓位)对待它。
我们往往拿投机的心态做投资，又拿投资的长期持有做投机。

PART 2 / 工具篇

《助推》:知道自己的弱点,就为自己设计助推

《助推 NUDGE》终极版 · 理查德·塞勒 / 卡斯·桑斯坦
想健身? 把运动鞋放在床边
想少花钱? 删除购物 App
想多读书? 把手机放远,把书放近
想改变投资操作中的坏习惯 → 设计改变行为的锚点

两部手机:独立交易手机,物理隔离

独立交易手机:只装交易/看盘 App,只在下单时打开
选一台旧手机,装上所有交易 / 看盘 App;与日常生活手机严格分开,只在需要下单时打开
想看价格嫌麻烦 / 出门没带 / 忘充电……看盘次数明显降低
不被 App 营销提醒打扰,降低焦虑,更多时间生活看书
交易时目的性增强,实际交易时间明显缩短

检查清单:下单之前看一遍,按原则办事,不要骗自己

设计自己的操作清单,下单之前看一遍,增强仪式感
晚上不交易美股——少亏很多钱
不做空、零杠杆现货——没有爆拉爆仓风险,晚上睡得香
涨时想着卖个好价钱(不 FOMO);跌时想着买个好价钱(不恐慌)
至少分 3 次建仓——给自己足够犯错空间,心态更稳
单次 ≤5%——不会一次子弹打光

定期复盘:每季度 1 小时,评的是决策质量,不是盈亏

结果好 ≠ 决策对,结果差 ≠ 决策错。

PART 3 / 信息篇

构建差异化信息源

你的认知天花板,由你的信息源质量决定。必须像管理饮食一样,精心管理你的信息摄入。
去除噪音:多看高价值群、多看深度访谈、多看 X;少看朋友圈,删除抖音
建立信息清单:限制数量——公众号 50、推特 200、知识星球 5、付费社群 3;三条直接过滤——没有明确出处 / 没有独立观点与可验证逻辑框架 / 人品不行的人或机构
多看付费内容:付费即门槛,浓度远大于免费;付费公众号 / 社群 / 知识星球 / 付费 X / substack / 华尔街日报 / 巴伦周刊;给信息源建立评估框架,有进有出、良性循环

构建自己的个人投资知识库

知识库「全部知识」:记录有价值的视频、文章和资料,构建个人投资认知体系
好的知识进,低质量/过时的知识出——学习本质是知识内化
每条记录:个人感想 + AI 总结 + AI 复盘(验证观点)
标签体系:股票 / ETF / 行业 / 投资哲学……剩下交给算法
做好记录只问一句:这条内容一年后看,值得我再读一遍吗?打好标签——行业、标的、投资哲学……剩下的交给算法

利用 AI 帮我回顾:我的今日阅读算法,不要被新闻埋没,旧闻更重要

今日阅读算法:六类规则卡,让算法帮我回顾
未读知识:每日从知识库随机抽 4 篇,补齐缺口
反复阅读:投资哲学/人生哲学类,越久未读权重越高,90 天冷却
观点回顾:汇总近 90 天"关键信号"观点,组成回顾任务
投资感悟 / 犯规注意 / 绝对杜绝:20 条轮转温习,不再有记录被永久截断

利用 AI 定期复盘信息来源:这个作者还值得读吗?

例:AI 逐条验证 Druckenmiller 2024-11 访谈观点
站在今天看,作者哪些观点符合预期,哪些被证伪,哪些有待观察?
例:AI 逐条验证 Druckenmiller 2024-11 访谈——通胀二次反弹判断完全符合预期
观点经常被打脸 → 还值得读吗?
观点经常被验证 → 即使说话不好听,也值得阅读

用 AI 构建投资人能力评分卡 投资类 / 投机类,绝不能搞混

分类方法、两套评估模型与维度定义
按主导风格先归类,两类各用一套模型、各自独立排名

PART 4 / 执行篇

心得 1:用 AI 来执行,金字塔加仓 + DCA

金字塔参数设置 + 双向挂单预览(TSLA 示例)
软件实现成本趋近于 0,构建个性化工具极其方便
正三角买入:1 年低点上方分档挂单,越跌买越多,现金占比设上限
倒三角卖出:1 年高点下方边涨边出,持仓占比设上限
振幅 × 档位倍率参数化 → 双向 GTC 挂单,执行不靠情绪

心得 2:用 AI 克隆策略,期权策略面板

近 ATM 行权价分析 + ATM 年化收益率曲线(Term Structure)
期权太复杂:到期日、CALL/PUT、买卖方向、价格……用工具把复杂度收敛成两个问题:
卖 PUT 之后,年化收益多少?(ATM 年化收益率曲线)
万一被行权,实际持有成本多少?= 行权价 − Put 权利金
实际卖出价 = 行权价 + Call 权利金

心得 3:让 AI 看到自己的仓位,每周自动体检

AI 周报:本周关键变化 + 纪律体检红绿灯

AI 直接分析仓位变化,给出调整建议,辅助决策
纪律体检红绿灯:持仓数、重仓数、杠杆、行业配比逐项对照
