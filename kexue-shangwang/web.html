科学上网清单 V1.3

一份自用的、能跑通的配置清单。

吴斯 Aaron · 更新于 2026-07-23

一次性把梯子说清楚：付费机场 → 装 Clash 客户端 → 导入订阅 → 开 TUN 虚拟网卡 → 用美区 Gmail 登录。以下是我自己在用、目前还算稳定的一套。这是个人自用记录，仅供参考，请自行判断、合规使用，风险自负；链接中的注册码为我的个人邀请码。

STEP 01 · 科学上网

把梯子搭起来

1购买付费 VPN（机场）

我用的是这个，目前还算稳定。
前往注册 →

2下载安装 VPN 客户端

机场网站里一般有客户端下载链接；也可以直接去 Clash Verge 的 GitHub 下载对应系统安装包。
一定要用管理员模式安装：github.com/clash-verge-rev/clash-verge-rev/releases
Clash Verge 的 GitHub Releases 下载页

3复制 Clash 订阅地址

在机场后台复制你的 Clash 订阅链接。
机场后台 · 复制订阅地址

4把订阅地址导入客户端

回到 Clash Verge，粘贴订阅地址并导入，拉取节点。
导入订阅 · 拉取节点

5开启 TUN 虚拟网卡模式

进入设置页，找到「虚拟网卡 / TUN 模式」，右侧有一个小扳手图标，点击并安装；
安装完毕后，退出并重启 Clash；
Mac 上一定要用管理员模式安装虚拟网卡，否则会出现「明明开了却依然翻不出去」的问题。
开启 TUN 虚拟网卡 · 点小扳手安装

6设置好并开启 VPN

选好节点 · 开启代理

7测试是否成功

打开测试页面确认已经出墙、节点可用。
测试 · 确认已出墙
STEP 02 · 登录 Claude

用美区 Gmail 登录

8准备美区 Gmail，登录 Claude

准备一个 Gmail 账户（注册时居住地区选择美国，填一个美国地址）。
打开 Claude 客户端 → 选择「用 Google 账号登录」→ 选这个美区 Gmail，搞定。
付费机场 × Clash Verge × TUN 网卡 × 美区 Gmail
